# Open release candidate

`rc/0.283.0` is open for NMI erasure confirmation, proposal cancellation budgets, PgBouncer transaction pooling for embedded hosts, operator-triggered provider refresh, and usage limits with per-process leases, daily usage settlement and the Go SDK gate. It also carries the pre-v1 public-surface cleanup: the Go API (`Config` as plain data beside `Deps`, an injected `*slog.Logger`, each type in the package hosts import, derived handles, a `*Client` generated from the route catalog, and typed enums, currencies and error codes); the docs cut to one integration guide; browser code under `web/` and a trimmed `scripts/`; and CI that vets every module and build tag and runs the database-free package tests.

Work lands on the one open release candidate named here, never on `master`: push to it after a local build, and its push check runs the light tier. Pull requests into it are optional. An RC is named for the version it becomes (`rc/0.280.0`). When one is cut from master, this file names it and what it is for; when it merges to master the branch is deleted and this file says none again. See [`.claude/CLAUDE.md`](.claude/CLAUDE.md) "Branches".
