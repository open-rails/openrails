# Open release candidate

`rc/0.283.0` is open for NMI erasure confirmation and proposal cancellation budgets.

Feature pull requests target the one open release candidate named here, never `master`. An RC is named for the version it becomes (`rc/0.280.0`). When one is cut from master, this file names it and what it is for; when it merges to master the branch is deleted and this file says none again. See [docs/ci.md](docs/ci.md).
